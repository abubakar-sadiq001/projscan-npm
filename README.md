# ProjScan CLI

This is the official npm installer for [ProjScan](https://github.com/abubakar-sadiq001/projscan) – a fast, lightweight project scanner built in Go.

## Installation

```bash
npm install -g projscan-cli
```

## Usage

Once installed, the projscan command is globally available:

```bash
projscan .
```
